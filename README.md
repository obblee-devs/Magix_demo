# Magix Household Product — React Landing Page Demo

A Vite + React demo landing page created from the current Magix Household Product catalogue.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
```

The deployable output will be generated in `dist/`.

## Git quick start

```bash
git init
git add .
git commit -m "Initial Magix landing page"
```

Then connect the repository to GitHub/GitLab and deploy to Vercel, Netlify, or your hosting provider.

## Main files

- `src/App.jsx` — page sections/content
- `src/styles.css` — complete responsive styling
- `public/assets/` — catalogue-derived demo imagery
- `public/Magix-Product-Catalogue.pdf` — linked catalogue

## Notes

This is a demo marketing page. Before production, confirm final phone numbers, email, address, legal text, product images and whether the catalogue PDF should remain publicly downloadable.
